# 主体间公理调研

**本页持续整理一项研究问题：人和 AI 怎样形成可以共同依靠的信念，这些信念凭什么值得承诺，又怎样在共同生活中接受检验和修正。**

固定阅读页：[主体间公理调研](https://prakasa-labs.github.io/prakasa-research/)

## 调研范围

研究材料包括社会规范与信念、共同知识与共同承诺、制度与代表、异议和退出、文化传承、文明评估，以及 AI researcher 关于 AI 社会行为的文章。理论论文、实证研究、历史材料和 AI 系统研究各自回答不同问题；它们为 Prakāśa 提供研究依据，不直接替 Prakāśa 作价值结论。

## 条目结构

每项调研按以下顺序整理：

1. **研究类目**
2. **文章标题与作者**；AI researcher 文章在原文可查时保留提交时间、摘要、Comments、Subjects、Cite as 和版本记录
3. **内容概述**：研究问题、材料或方法、直接观察到的结果
4. **调研结论**：研究结果对主体间公理问题的启发、适用边界和仍待回答的问题
5. **原文或相关资料链接**

缺少的论文信息不猜测；内容概述不代替原文，调研结论不冒充作者结论。

## 证据整理规范

- 区分个人私下认同、对他人立场的估计、公开表达、实际行为，以及是否认可规则约束；不能用其中一项替代另一项。
- 区分理论推导、实验结果、历史记录和 AI 系统输出，说明证据直接支持什么、不能推出什么。
- 交代研究对象、样本、方法、时间和关键限制；未记录、未询问或资料缺失，不写成同意。
- 不把留下、服从、参与或公开表态单独当成自愿认同的证明；留意没有参与、退出或难以发声的人。
- AI 生成关于自身的陈述，不单独证明其具有主观信念或体验。
- 发现来源、论文版本或结论有变化时，注明依据并修订相关条目；保留争议与未知，不把暂时判断写成定论。
